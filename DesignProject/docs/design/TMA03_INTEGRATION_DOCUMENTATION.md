## Error Detection Capabilities

### Critical Errors Detected:
1. **Type Mismatches**: `x := 1.5` where x is integer
2. **Undefined Variables**: Usage before declaration
3. **Duplicate Declarations**: Multiple declarations of same identifier
4. **Function Call Errors**: Wrong argument count/types
5. **Array Bounds**: Index out of range access
6. **Missing Returns**: Non-void functions without return
7. **Inheritance Errors**: Invalid class hierarchies
8. **Scope Violations**: Access to private members

### Advanced Warnings:
1. **Unused Variables**: Declared but never used
2. **Unreachable Code**: Code after return statements
3. **Performance Issues**: Inefficient patterns
4. **Style Issues**: Naming conventions
5. **Security Issues**: Potential vulnerabilities
