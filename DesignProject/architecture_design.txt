COMPILER ARCHITECTURE OVERVIEW:
===============================

1. FOUR-PHASE COMPILATION PIPELINE:
   ├── Phase 1: Lexical Analysis (TMA1)
   │   ├── Input: Source code (.txt files)
   │   ├── Output: Token stream
   │   └── Files: scanner.l, lex.yy.c
   │
   ├── Phase 2: Syntax Analysis (TMA2)
   │   ├── Input: Token stream
   │   ├── Output: Abstract Syntax Tree (AST)
   │   └── Files: parser.y, parser.tab.c
   │
   ├── Phase 3: Semantic Analysis (TMA3)
   │   ├── Input: AST
   │   ├── Output: Annotated AST + Symbol Tables
   │   └── Files: semantic.c, ast.c, error_handler.c
   │
   └── Phase 4: Code Generation (NEW)
       ├── Input: Annotated AST + Symbol Tables
       ├── Output: x86-64 Assembly Code
       └── Files: codegen.c, register_allocator.c

2. REGISTER ALLOCATION STRATEGIES:
   ├── Linear Scan Algorithm
   ├── Graph Coloring Algorithm

3. MEMORY MANAGEMENT:
   ├── Stack Frame Management
   ├── Variable Lifetime Analysis
   ├── Automatic Spill/Reload Generation
   └── Function Call Conventions

4. OUTPUT FILE GENERATION:
   ├── Dynamic file naming (input_filename_output_type.txt)
   ├── Comprehensive analysis reports
   ├── Symbol table documentation
   └── Performance metrics tracking
